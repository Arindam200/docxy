# CLA signatures

This branch exists only to store Contributor License Agreement signatures. The
`cla` workflow on `main` writes them to `signatures/version1/cla.json` when a
contributor replies to their pull request agreeing to [CLA.md](https://github.com/Arindam200/docxy/blob/main/CLA.md).

There is no project code here. Do not merge this branch into `main`, and do not
edit the signature file by hand.
